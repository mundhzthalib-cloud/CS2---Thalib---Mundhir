# Travel Fare Calculator

## Description
This program calculates the total of the passenger's fare.

## Version 1 - Original code without input validation
- Input: Accepts a passenger's name, the distance travelled, and the total number of passengers.
- Process: Calculates and displays the total fare.
- Output: Total fare.
- Does not include input validation.

## Version 2 - Updated code with input validation
- Input: Accepts a passenger's name, distance, and number of passengers with strict validation rules.
- Process: Validates that the name is not blank, and that distance and passengers are valid positive numbers using loops and error handling.
- Output: Displays the validated passenger name and total fare.
